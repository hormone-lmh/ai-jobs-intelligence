# AI 岗位情报分析系统

本机运行的岗位采集与分析原型。当前使用 **FastAPI + SQLite + 原生 HTML/CSS/JavaScript**，不需要 Node 构建前端。数据由浏览器扩展跟随本人浏览上报，或手动粘贴岗位正文。

## 启动

```powershell
pwsh -ExecutionPolicy Bypass -File scripts\setup.ps1
pwsh -ExecutionPolicy Bypass -File scripts\start.ps1
```

已有 `backend/.venv` 时可直接运行第二条。`start.ps1` 在后台运行服务并检查首页，重复执行不会重复启动；开发时可用 `dev.ps1` 在终端开启自动重载。打开 http://127.0.0.1:8000/ 。更新代码后重启服务；更新扩展后在 `chrome://extensions/` 重新加载扩展，再刷新招聘页面。

## 已实现

- 按职位 ID 去重，保存列表信息、原始上报及当前岗位正文。
- 正文 / 标题与标签两种独立技能统计；显示分母、样本量与 JD 覆盖率。
- 岗位或公司搜索、城市筛选、技能筛选、分页。
- 本地查看岗位正文、各技能对应原文片段与来源。
- 粘贴 BOSS 职位链接与正文，保存后重新分析。
- 新正文替换旧正文技能；旧记录回放不覆盖新内容。
- 扩展检查 HTTP 与业务结果，失败后退避重试本地上报；同页面内容变化重新上报。
- 外部文本使用 DOM 文本渲染，链接只允许 BOSS HTTPS 职位详情地址。

- 公司视图：公司搜索、城市筛选、岗位数/JD 覆盖、正文技能和精确岗位下钻。
- 需求对比：两组岗位关键词/城市/公司自由组合，对比样本数、正文技能、学历及经验分布；显示重叠与小样本提示。

## 当前限制

**这些数字只是已搜集样本，不代表全平台、招聘人数或当前仍在招的职位。**

- 自动采集依赖本人浏览页面，不会自行搜索、翻页或定时巡检。
- 技能是词典提及识别，尚不区分必备、加分、否定及职责语境。
- 不自动判定 AI 岗位类别；请在来源端选定目标岗位，再在本地筛选。
- 字体混淆薪资保留不可识别标记，不参与薪资比较。
- 尚未实现时间趋势、岗位变更对比、CSV/Excel 导入和大模型分析。
- 正文结构化表仅保留最新版本；原始上报保留历史，尚无历史对比界面。
- 详情 DOM 选择器需要真实页面验证；无法取得正文时可手动粘贴，不回退到整页文本。

## 文件

- `backend/app/`：后端、解析、技能提取；`static/` 为实际前端。
- `extension/`：Chrome / Edge 扩展。
- `config/taxonomy.yaml`：技能词典；修改后需重启并回放原始数据重新提取。
- `data/jobs.db`：真实数据库；`data/raw/extension/`：原始上报。
- `tests/`：隔离数据库回归测试；不使用真实岗位数据。
- `docs/02-使用说明.md`：安装扩展、操作流程和故障处理。
- `docs/03-指标口径.md`：统计定义与已知限制。

`frontend/` 是早期预留目录，当前未使用。`docs/00` 与 `docs/01` 保留原始规划和历史探测记录，当前功能以本文和使用说明为准。当前运行时不加载 `sources.yaml` 中的旧采集适配器规划。

## 验证

```powershell
pwsh -ExecutionPolicy Bypass -File scripts\test.ps1
```

测试数据库使用内存，临时原始记录位于 `data/test-runs/`。浏览器验证脚本 `scripts/verify_ui.py` 使用独立数据库和随机本机端口，不访问 BOSS、不修改真实数据；需本机已安装 Chrome。
