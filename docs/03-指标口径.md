# 指标口径

| 指标 | 定义 |
|---|---|
| 已搜集岗位 | 当前本地数据库按平台职位 ID 去重后的职位发布数，包括详情先到的占位记录 |
| 样本中的公司 | 岗位记录中非空公司名称的去重数；非当前在招公司数 |
| JD 覆盖率 | 有保存正文的去重岗位数 / 全部岗位数；零样本显示 0% |
| 正文技能提及率 | 正文提及该技能的去重岗位数 / 当前搜索和城市范围内有正文的岗位数 |
| 摘要技能分布 | 标题或标签提及该技能的去重岗位数 / 当前搜索和城市范围内全部岗位数 |
| 最近见到 | 最近一次保存该岗位列表或详情的采集时间，不等于发布时间 |

正文与摘要独立统计；同一技能在同一岗位中多次出现只计一个岗位。标题与标签共同出现只保留一条摘要证据，正文证据独立保存。分母包含有正文但无技能命中的岗位，避免人为提高比例。

技能统计的筛选为 q（岗位/公司模糊搜索）和 city（城市精确匹配）。点击技能只缩小岗位列表，不改变统计分母。顶部总览为全库样本。

没有正文时正文技能列表为空，不自动回退摘要。列表不保证全是 AI 岗位，也没有岗位方向分类器。技能词典结果是提及，不是必备要求；否定、加分项及非技术同名表达需要人工结合证据判断。

列表重采覆盖摘要技能，正文重采覆盖正文技能。较旧详情依据正文采集时间拒绝覆盖；较旧列表依据最近见到时间拒绝覆盖（占位岗位允许补齐），所以极端乱序情况下可能保留较旧列表字段，但不会让新正文退回旧版。跨批次更新时间不代表市场需求涨跌。

原始上报保存历史，结构化正文只保留最新版本。暂未实现口径指纹、断档趋势、招聘状态推断、必备/加分分类或薪资比较。早期技术方案中的这些指标是规划，不是现有功能。

## 横向需求对比

`POST /api/intelligence/compare` 接收 left/right，各自包含 keyword、city、company。keyword 对岗位标题作字面包含匹配（不将 % 或 _ 当通配符），其余字段精确匹配。允许任意条件为空，也允许两组重叠。

正文技能比例分母为各自有 JD 的岗位数；分母为零返回 null。技能差值为 `(A 比例 - B 比例) × 100` 个百分点；任一分母为零不计算。职位数量是已采集样本量，不能据此推断两地市场规模。正文覆盖率差异、采集偏差和分组重叠需要结合展示的样本量解读。

公司视图按来源中的公司名称精确分组，尚未合并公司别名、品牌与法人主体。排名按样本职位数排序，不是招聘规模排名。
